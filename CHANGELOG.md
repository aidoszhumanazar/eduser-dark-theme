# Changelog

## 0.1.3

- New Marketplace page: hero banner, Python / JavaScript / SQL / HTML & CSS screenshots, light vs dark comparison and a palette table.
- Added GitHub repository links.

## 0.1.2

- Easier on the eyes: background saturation reduced from 63% to 32% (`#100C35` → `#171A2D`), shifted from purple to a calm indigo-blue.
- Neutral sidebar, panel, menus and borders; softer main text (`#DCDEF2`) to reduce glare.
- Brighter comments for better readability; status bar always EDUSER blue.
- Syntax colors unchanged.

## 0.1.1

- Works out of the box for students who set up the EDUSER light colours directly in settings.json: when EDUSER Dark Theme is selected, those old colours are automatically scoped to EDUSER Light Theme, so the dark theme is no longer covered by a white editor. Other personal settings are never touched.

## 0.1.0

- First release of EDUSER Dark Theme.
- Deep indigo workbench with EDUSER blue status bar and red accents.
- Saturated syntax colors mirroring the EDUSER Light Theme groups for SQL, HTML, CSS, JavaScript and Python.
- Italic control flow, golden types, decorators, TypeScript, JSON and Markdown colors.
- Styled menus, widgets, notifications, terminal palette and diff colors.
